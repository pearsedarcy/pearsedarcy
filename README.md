# Pearse D’Arcy

Software engineer in Innsbruck.

I build Django platforms that run live medical-training events, self-hosted AI with human guardrails, and the agent workflows that ship both.

## What I do

- **Platform building.** Django, PostgreSQL and Celery systems of record for live events: bookings, packing, inventory, staffing, certificates and a video platform that records surgical stations as they happen.
- **Self-hosted AI in production.** Local models (Qwen3-VL, vLLM, LangGraph) doing real jobs, with a person approving anything that leaves the building.
- **Agentic engineering.** Claude Code run as a one-person, many-agent team: isolated worktrees, hooks that block destructive git, adversarial review before merge.

Most of this work is private. The case studies, with the details that can be shared, are at [pearse.dev/work](https://pearse.dev/work/).

## Now

- Tightening observability and incident triage for production Django apps.
- Writing up what works in agent-assisted engineering, and what does not.
